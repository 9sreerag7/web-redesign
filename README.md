
# Wikiverse 🌍

A modern UI/UX redesign concept inspired by **Wikipedia**, built using HTML, CSS, and JavaScript.

Wikiverse transforms the traditional encyclopedia experience into a clean, modern, and visually engaging knowledge discovery platform.

## ✨ Features

- Modern and responsive homepage
- Interactive Wikipedia search
- Explore topics and categories
- Featured article section
- Random article discovery
- Dark and light mode
- Mobile-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser or use VS Code Live Server.
